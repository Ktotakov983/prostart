# ProStart Web ⛵

Веб-копия интерфейса стартового таймера **Velocitek ProStart** для парусных гонок.
Работает прямо в браузере, ничего не нужно устанавливать.

### [→ Открыть приложение](https://ktotakov983.github.io/prostart/)

## Возможности

- **Старт-таймер** с синхронизацией (GUN, +1/−1 минута), настраиваемая длительность отсчёта
- **Линия старта**: разметка по PIN/BOAT, дистанция и сторона до линии, фаворитный конец по ветру (BIAS)
- **Режим гонки**: курс, скорость, индикатор захода/отхода ветра (TRIM), максимальная и средняя (10с) скорость
- **Курс** из GPS или компаса телефона — с поправкой на то, как закреплён телефон
- **Крен (heel angle)** по датчику ориентации
- **История заездов**: автосохранение, график скорости, карта маршрута с линией старта, переименование и удаление записей
- **Блокировка экрана** — защита от случайных нажатий каплями воды
- Тёмная/светлая тема, полноэкранный режим, экспорт GPS-лога в CSV

Подробное руководство — прямо в приложении, в меню → «Руководство».

## Технически

Один самодостаточный файл (`index.html`) — без сборки, без зависимостей, кроме
Leaflet (карты). Работает офлайн, кроме тайлов карты. Геолокации требуется
HTTPS (или localhost) — поэтому приложение открывается по ссылке, а не как
локальный файл.

## StartGun — приложение для Android с кнопками громкости

Ограничение веб-платформы: браузер не может перехватывать физические кнопки
громкости телефона. Для тех, кому это важно (управление GUN/сменой режима
кнопками громкости во время блокировки экрана), есть отдельное Android-приложение
**StartGun** — тонкая нативная обёртка над этим же сайтом с перехватом кнопок
на уровне системы. См. [Releases](../../releases) для APK.

Веб-версия при этом остаётся полностью самостоятельной и не требует StartGun.
