# ProStart Web ⛵

Стартовый таймер для парусных гонок в браузере телефона.
Работает прямо в браузере, ничего не нужно устанавливать.

### [→ Открыть приложение](https://ktotakov983.github.io/prostart/)

## Возможности

- **Старт-таймер** с синхронизацией (GUN округляет вниз до целой минуты, +1/−1 минута), настраиваемая длительность отсчёта; во время гонки новый отсчёт — двойным нажатием GUN
- **Линия старта**: разметка по PIN/BOAT, дистанция от носа (с поправкой на нос) и сторона до линии, пейсинг по курсу над грунтом, фаворитный конец по ветру (BIAS)
- **Режим гонки**: курс, скорость, индикатор захода/отхода ветра (TRIM), максимальная (2 с) и лучшая средняя (10 с) скорость
- **Курс** из GPS или компаса телефона — с поправкой на то, как закреплён телефон
- **Крен (heel angle)** по вектору гравитации — работает и при вертикальном креплении телефона
- **Линия и настройки сохраняются** и переживают перезагрузку страницы
- **История заездов**: автосохранение (до 6 часов в записи, старые записи удаляются при нехватке памяти), график скорости, карта маршрута с линией старта, переименование и удаление записей
- **Блокировка экрана** — защита от случайных нажатий каплями воды
- Тёмная/светлая тема, полноэкранный режим, экспорт GPS-лога в CSV

Подробное руководство — прямо в приложении, в меню → «Руководство».

## Технически

Один самодостаточный файл (`index.html`) — без сборки, без зависимостей, кроме
Leaflet (карты). Работает офлайн, кроме тайлов карты. Геолокации требуется
HTTPS (или localhost) — поэтому приложение открывается по ссылке, а не как
локальный файл.

## StartGun — приложение для Android

### [⬇ Скачать StartGun.apk](https://github.com/Ktotakov983/prostart/releases/download/startgun-v1/StartGun.apk)

Браузер не умеет перехватывать физические кнопки громкости телефона — это
ограничение платформы, не баг. **StartGun** — тонкая нативная Android-обёртка
над этим же сайтом, которая умеет то, чего не может веб-версия:

- **Управление кнопками громкости во время блокировки экрана**: Volume+ жмёт
  GUN и переключает на экран START, Volume− переключает режим START/RACE.
  Во время гонки новый отсчёт, как и на экране, запускается двойным Volume+.
  Перехват происходит на уровне системы (Activity), а не веб-страницы, поэтому
  работает надёжно на любом устройстве Android.
- Показывает тот же сайт **ktotakov983.github.io/prostart** в полноэкранном
  виде — все обновления веб-версии прилетают в приложение автоматически, без
  переустановки APK.
- Все возможности веб-версии (см. выше) работают внутри приложения так же, как
  в браузере — GPS, история заездов, блокировка экрана и т.д.

Это debug-сборка (не из Google Play) — при установке Android попросит
разрешить «Установку из неизвестных источников» для приложения, из которого
её открываешь.

Веб-версия при этом остаётся полностью самостоятельной и не требует StartGun.
